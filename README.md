Expense Manager

Features
- User Registration & Login
- Password Hashing
- User Profile Management
- Change Password
- Expense CRUD
- Expense Categories
- Dashboard Statistics
- Authentication & Sessions
- SQLAlchemy ORM
- Flask-Migrate
- Bootstrap UI

Tech Stack
- Python
- Flask
- SQLAlchemy
- SQLite
- Flask-Migrate
- Jinja2
- Bootstrap

Getting Started
- Clone repository
- Create virtual environment
- Install dependencies
- Run migrations
- Start the application

## Installation

```bash
git clone https://github.com/akhtarn963/expense-manager.git
cd expense-manager

python -m venv venv

# Windows
venv\Scripts\activate

pip install -r requirements.txt

flask --app app.py db upgrade

python app.py
```
