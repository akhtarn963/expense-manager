# Expense Manager

A Flask-based expense management application built while learning Python and Flask.

## Features

- Expense CRUD
- SQLite database
- SQLAlchemy ORM
- Flask-Migrate
- Bootstrap UI
- Dashboard statistics

## Tech Stack

- Python
- Flask
- SQLAlchemy
- Flask-Migrate
- SQLite
- Bootstrap 5

## Installation

```bash
git clone <repository-url>
cd expense-manager

python -m venv venv

# Windows
venv\Scripts\activate

pip install -r requirements.txt

flask --app app.py db upgrade

python app.py
```
